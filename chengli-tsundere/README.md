# Claude-Codex pet

橘色长发、花饰与黑白橙裙装的傲娇大小姐，适用于 Codex 桌面端的自定义宠物。

把整个 `chengli-tsundere` 文件夹放到 `%USERPROFILE%\.codex\pets\` 下，然后在 Codex 宠物列表中选择 **Claude-Codex pet**。如果列表未刷新，重新打开 Codex。

`pet.json` 与 `spritesheet.webp` 必须放在同一个文件夹中。内部 ID 为 `chengli-tsundere`，更新已有同 ID 宠物前可先备份旧文件夹。

动画图采用 Codex v2 格式：1536 × 2288 像素，8 列 × 11 行，每格 192 × 208 像素，透明 WebP。

角色设定见 `人设说明.md`；宠物包提供外观和动画，不包含自动对话或语音。
